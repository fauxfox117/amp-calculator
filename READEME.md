# Trimlight Amp Calculator

The **Trimlight Amp Calculator** is a React-based web app designed to help Trimlight installers calculate the exact number of amps needed for any lighting run. By inputting product details, spacing, and run length, installers can quickly determine where amps should be added to prevent voltage drop issues such as dimming or color failures.

## Why It’s Useful

When too many lights are run on one line, voltage drop reduces performance — lights dim, colors fail to change, or animations look inconsistent. Fixing these issues after installation wastes labor time, materials, and can delay job completion. This tool ensures correct planning _before_ the install begins, saving hours of rework and improving customer satisfaction.

## Features

- 🔢 **Accurate Amp Calculations** — Input light counts and run lengths to instantly get amp requirements.
- 📱 **Mobile-Optimized** — Built for quick use in the field on phones or tablets.
- ⚡ **Prevents Voltage Drop** — Ensures even power distribution and consistent lighting.
- 🏠 **Perfect for Full House Wraps** — Scales easily for large installations where multiple amps are required.
